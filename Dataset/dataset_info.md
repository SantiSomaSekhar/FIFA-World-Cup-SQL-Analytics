# FIFA World Cup Dataset

## Overview

This project uses a FIFA World Cup dataset containing player, match, team, and tournament statistics.

## Source

- Kaggle

## Dataset Contents

- Player Information
- Match Statistics
- Team Performance
- Tournament Details

## File Used

fifa_world_cup.csv

## Purpose

The dataset was used to:

- Design a normalized relational database
- Perform exploratory data analysis
- Solve business-oriented SQL questions
- Practice advanced SQL concepts
- Create SQL views
- Build an interactive Power BI dashboard

## Technologies Used

- MySQL
- SQL
- Power BI
- Git & GitHub

## Note

If the dataset is unavailable in this repository, download an equivalent FIFA World Cup dataset from Kaggle and import it using the SQL scripts provided in the `SQL` folder.
